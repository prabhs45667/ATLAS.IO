## Design Context

### Users
Hackathon judges and friends playing together in a browser. Quick sessions, competitive, social. The audience appreciates craft and visual polish — this needs to look like a product, not a prototype.

### Brand Personality
**Mysterious, cinematic, refined.** Like opening an old cartographer's case that turns out to contain advanced technology. The game should feel like a portal to another time — immersive and slightly eerie, never goofy or playful.

### Aesthetic Direction
- **Dark, warm antiquarian palette** — already established and working well. Deep umber background, copper accents, aged gold.
- **Perplexity vibes**: clean information hierarchy, generous whitespace, restrained UI chrome, sophisticated typography. The UI should feel intelligent and minimal, not decorated.
- **Anti-references**: GeoGuessr (too playful/cartoonish/goofy), generic gamification aesthetics, bright primary colors, chunky rounded UI.
- **Theme**: Dark mode. The panorama is the hero — UI should recede and frame it.
- **Fonts**: Brygada 1918 (display) + Hanken Grotesk (body) — keep these.

### Design Principles
1. **The panorama is sacred** — UI elements are overlays that whisper, not shout. Minimal chrome, maximum immersion.
2. **Earned complexity** — start spare, reveal depth through interaction. No visual clutter upfront.
3. **Cinematic restraint** — every decorative element must earn its place. Film grain, vignettes, ornaments are good; but less is more.
4. **Precision over personality** — spacing, alignment, and typography should feel obsessively tuned. Perplexity-level polish.
5. **Time as texture** — the vintage/antiquarian aesthetic should feel authentic, not cosplay. Subtle aging, not theme-park decoration.
